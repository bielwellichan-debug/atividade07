# Atividade 07 - Semana da Arte Moderna 🎨
Nesta atividade, em comemoração ao evento histórico da Semana da Arte Moderna de 1922, fomos instruídos a criar um site sobre uma obra ou artista que participou deste evento!

## Qual obra eu escolhi? 🖼️
Escolhi para realizar essa atividade o quadro "A Ventania" de Anita Malfatti, que retrata uma paisagem de um lugar que a pintora gostava muito nos Estados Unidos, seu país natal!

## O que foi cobrado? 🤔
Foi cobrado de nós que fizéssemos um site bonito, utilizando fontes do Google Fonts ou do DaFont, cores que combinassem entre sí e que utilizassemos as linguagens HTML e CSS.
